# Definition of Ready

Una historia está lista para desarrollo cuando:

- Tiene objetivo y usuario claramente identificados.
- Tiene criterios de aceptación verificables.
- Sus reglas de negocio están confirmadas.
- Se conocen los bounded contexts afectados.
- Se conocen los cambios de API, base de datos y seguridad.
- Tiene dependencias identificadas.
- El equipo puede estimarla y dividirla si es demasiado grande.
- El cliente conoce el resultado esperado.
