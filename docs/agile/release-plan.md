# Plan de releases

## Release 0 — Fundación técnica

Incluye estructura del repositorio, CI, configuración de ambientes, migraciones iniciales, health checks, logging y pruebas base.

## Release 1 — Catálogo e inventario

Incluye usuarios, roles, tenant, grupos, atributos, productos, precios, stock, movimientos y abastecimientos.

## Release 2 — Operaciones comerciales

Incluye vista previa, descuentos, costos adicionales, ventas, cancelaciones y actualización consistente del inventario.

## Release 3 — Gestión y observabilidad

Incluye dashboard, reportes, auditoría visible para administradores, backups probados, staging y despliegue controlado.

Cada release debe validarse con el cliente antes de ampliar el alcance.
