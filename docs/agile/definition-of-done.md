# Definition of Done

Una historia se considera terminada cuando:

- El código está implementado en la capa y bounded context correctos.
- La API y la base de datos están actualizadas cuando corresponde.
- Las reglas críticas tienen pruebas unitarias.
- El flujo tiene pruebas de integración o E2E cuando corresponde.
- Se validan autorización, tenant, idempotencia y concurrencia.
- No existen secretos ni datos reales en el código o fixtures.
- Lint, formato, build y pruebas pasan.
- La documentación y la trazabilidad están actualizadas.
- El cliente puede probar un incremento usable.
