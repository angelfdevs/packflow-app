# Product Backlog inicial

| Prioridad | Épico | Resultado esperado |
|---|---|---|
| P0 | Identity & Access | Inicio de sesión, sesión, roles, invitaciones y bloqueo de usuarios |
| P0 | Tenant & Business | Aislamiento de datos y configuración básica del negocio |
| P0 | Catalog & Pricing | Grupos, atributos, productos y precios configurables |
| P0 | Inventory | Stock, ingresos, ajustes, movimientos y concurrencia |
| P0 | Commercial Operations | Vista previa, descuentos, costos adicionales y venta confirmada |
| P1 | Inventory & Supply | Proveedores y abastecimientos opcionales |
| P1 | Dashboard | Indicadores resumidos para administradores |
| P1 | Reporting | Reportes de ventas, inventario, productos y abastecimientos |
| P1 | Security & Compliance | Auditoría, privacidad, backups y respuesta a incidentes |
| P1 | Deployment | CI/CD, QA, staging, health checks y rollback |

Cada ítem debe vincularse con historias de usuario, requisitos no funcionales, endpoint, entidades afectadas y pruebas.
