# Documentación técnico-legal pendiente

Antes del lanzamiento comercial deben revisarse con asesoría legal peruana:

- Términos de uso del SaaS.
- Política de privacidad.
- Política de cookies.
- Acuerdo de tratamiento de datos para clientes empresariales.
- Procedimiento de atención de derechos ARCO.
- Conservación, exportación y eliminación de datos.
- Canal de soporte y reclamos cuando corresponda al modelo comercial.

El footer debe enlazar a estos documentos, pero no sustituye su contenido.

No se deben afirmar garantías legales, tributarias, contables o de disponibilidad sin una revisión profesional y evidencia operativa.
