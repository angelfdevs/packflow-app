# Goal flows de Agilora

## Objetivo: controlar inventario

```text
Necesidad de conocer existencias
  -> Consultar stock actualizado
  -> Identificar producto bajo o agotado
  -> Registrar ingreso, abastecimiento, venta o ajuste
  -> Obtener movimiento confirmado
  -> Ver el resultado en otros clientes conectados
```

## Objetivo: responder a un cliente

```text
Solicitud de precio
  -> Buscar producto
  -> Ingresar cantidades
  -> Aplicar reglas y costos opcionales
  -> Calcular vista previa
  -> Informar subtotal, descuento, IGV y total
  -> Confirmar venta solo si el cliente compra
```

## Objetivo: administrar el negocio

```text
Administrador
  -> Revisar dashboard
  -> Consultar reportes
  -> Revisar auditoría y usuarios
  -> Ajustar configuración y reglas
  -> Supervisar operaciones sin bloquear el trabajo operativo
```
